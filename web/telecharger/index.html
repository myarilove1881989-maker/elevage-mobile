Installer en 3 étapes

  1. Téléchargez le fichier APK. Privilégiez le Wi-Fi si votre forfait Internet est limité, puis ouvrez le fichier depuis vos téléchargements.
  2. Autorisez cette installation si Android le demande. Dans les paramètres proposés, autorisez temporairement l’installation depuis votre navigateur ou votre gestionnaire de fichiers, puis revenez au fichier APK.
  3. Appuyez sur « Mettre à jour » si la 117 est installée. Ouvrez ensuite Élev’Age et connectez-vous. Vous pouvez désactiver l’autorisation d’installation une fois terminé.
Un avertissement peut apparaître. Cette application est distribuée hors du Play Store : votre navigateur, Android ou Play Protect peuvent afficher une alerte ou proposer une analyse. Vérifiez que vous êtes sur cette page officielle et laissez les contrôles de sécurité s’effectuer. Si l’installation est bloquée ou si une menace est signalée, contactez-nous avant de poursuivre.

Vous utilisez déjà Élev’Age ? Installez la mise à jour par-dessus l’application existante. Ne désinstallez pas l’application et n’effacez pas ses données. Si une incompatibilité de signature est signalée, contactez l’assistance.
